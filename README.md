# Diamond Design System

Website for the Diamond Design System Blender plugin, including the integrated Design Buddy jewelry model calculator at `/design-buddy/`.

This repository is prepared for React + Vite deployment on Hostinger.

## Pages

- `/` — Diamond Design System marketing site
- `/design-buddy/` — 3D jewelry model viewer, weight/cost calculator, labor estimate, history, and PDF report export
- `/payment-confirmed` — purchase confirmation page
